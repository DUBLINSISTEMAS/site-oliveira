# Engenharia Reversa — Babbo Giovanni

> Pizzaria histórica de São Paulo (desde 1917). A landing page combina identidade italiana clássica (vermelho/preto/branco) com tipografia moderna sans-serif e seções de storytelling, cardápio, depoimentos e franquias.

---

## 1. Design System

A paleta segue a identidade visual tradicional da marca: vermelho italiano forte como cor primária, preto/cinza-escuro como fundo dominante e branco para contraste. Tons de cinza intermediários estruturam superfícies e formulários.

## 2. Tipografia

A página usa a família **Halcom** (sans-serif geométrica) como tipo principal, com fallback para system-fonts. Combina pesos `300–700` para criar hierarquia clara entre títulos impactantes e corpo legível.

### 2.1 Família e Fallbacks

```css
--font-sans: "Halcom", -apple-system, BlinkMacSystemFont,
             "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
--font-display: "Halcom", "Halcom Bold", sans-serif;
```

## 3. Layout

A página é montada em blocos verticais full-bleed, cada um com um container central limitado. A estrutura herda convenções do WordPress (`wp-site-blocks`, `is-layout-flex`, `is-layout-grid`).

### 3.1 Containers

| Token | Largura | Uso |
|-------|--------:|-----|
| `--content-size` | `800px` | Blocos de texto/conteúdo padrão |
| `--wide-size` | `1200px` | Seções com mídia, cards, grids |
| `--form-size` | `600px` | Formulários centralizados |
| Full bleed | `100vw` | Background de seções |

### 3.2 Grid & Flex

- **Grid principal**: CSS Grid com `gap: 24px`, colunas auto-fit ao redor de `minmax(260px, 1fr)` em listagens de produtos.
- **Hero**: flex column centralizado verticalmente, `min-height: 90vh`.
- **Cards de produto**: grid 3 colunas em desktop, 2 em tablet, 1 em mobile.
- **Depoimentos**: grid 3 colunas em desktop, scroll horizontal em mobile.

```css
.section {
  width: 100%;
  padding-block: clamp(64px, 8vw, 120px);
}
.container {
  max-width: 1200px;
  margin-inline: auto;
  padding-inline: clamp(16px, 4vw, 32px);
}
.grid-cards {
  display: grid;
  gap: 24px;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
}
```

### 3.3 Espaçamento (escala 4px)

## 7. Notas de Implementação

1. **Fonte Halcom**: é proprietária. Em projetos sem licença, substitua por **Poppins**, **Manrope** ou **Plus Jakarta Sans** — todas mantêm o caráter geométrico-amigável.
2. **Tema escuro nativo**: a paleta toda é dark; não há toggle de light mode na original.
3. **Ícones**: a página usa SVGs custom (logo) e emojis pontuais (🍕). Para um clone, use Lucide ou Phosphor.
4. **Acessibilidade**: contraste do `#BE1522` sobre `#171717` ≈ 4.97:1 (passa AA para texto grande). Para corpo pequeno, prefira branco sobre vermelho.
5. **Animações**: leves — apenas `translateY` em hover (-1 a -4px) e fade/blur em scroll. Nada de parallax pesado.
6. **WhatsApp flutuante**: presente em todo o site, posição fixed bottom-right.
7. **Estrutura WordPress**: a original usa blocos do WP. Para um clone moderno, prefira Next.js + Tailwind ou Astro.
